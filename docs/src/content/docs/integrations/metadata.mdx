Aurral uses hosted services for artist pages, album details, and catalog search. Aurral uses fallback services if the primary services fail.

## Defaults

Most installs use Aurral's hosted metadata and search backends with no extra configuration.

## Custom providers

Admins can configure metadata hydration and the Aurral Search catalog backend at `/settings/metadata`.

The metadata page does not appear in the main settings navigation.

Use custom providers when you self-host search infrastructure or need alternate metadata sources.

## Sponsorship

Hosted metadata and search services run on personal infrastructure. These services can sometimes be unavailable.
