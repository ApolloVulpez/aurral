Aurral uses hosted metadata and search services for artist pages, album details, and catalog search. Fallbacks exist when those services are unavailable.

## Defaults

Most installs use Aurral's hosted metadata and search backends with no extra configuration.

## Custom providers

Admins can configure metadata hydration and the Aurral Search catalog backend at `/settings/metadata`.

This advanced page does not appear in the main settings navigation.

Use custom providers when you self-host search infrastructure or need alternate metadata sources.

## Sponsorship

Hosted metadata and search run on personal infrastructure. Thus, these services can sometimes be unavailable.

[Sponsoring development](https://github.com/sponsors/lklynet/) helps keep these services reliable.
