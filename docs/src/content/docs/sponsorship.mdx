Aurral is open source software for the self-hosting community. Sponsorship supports the project and its infrastructure.

## What sponsorship supports

- Aurral maintenance and releases
- Hosted metadata and search services
- Cloud capacity when personal infrastructure is not sufficient

The hosted services provide artist pages, album details, and catalog search. Backup services are available if a primary service fails.

Sponsorship helps make the default services more reliable.

## Become a sponsor

Support Aurral through [GitHub Sponsors](https://github.com/sponsors/lklynet/).

Sponsorship is optional. You can also use Aurral, report issues, or improve the docs.

You can also help users in [Discord](https://discord.gg/cpPYfgVURJ).
